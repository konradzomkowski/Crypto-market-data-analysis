# Crypto Market Data Analysis – Mini Produkt Fintech

Projekt w Pythonie pokazujący bieżącą cenę BTC/USDT, analizę procentowej zmiany ceny, trend i wizualizację danych z Binance API.

## Funkcjonalności
- Pobiera aktualną cenę BTC/USDT
- Pobiera historyczne dane świec (ostatnie 30 minut)
- Generuje wykres ceny zamknięcia 

## Technologie
- Python 3.x
- Biblioteki: `requests`, `pandas`, `matplotlib`
- Publiczne API Binance (bez klucza)
